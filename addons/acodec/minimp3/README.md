# minimp3

This directory contains the bundled minimp3 headers used by Allegro's MP3
codec support.

- Upstream: <https://github.com/lieff/minimp3>
- Snapshot: `ea99364f61c14656440e8d77e9c233ccf3124633`
- License: CC0 1.0 Universal (see `LICENSE`)

The headers are kept as an upstream snapshot. Local integration belongs in
`addons/acodec/mp3.c`, not in these files.
